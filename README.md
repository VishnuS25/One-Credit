# One-Credit Multi-Agent System Architecture Experiments

This repository contains three React/Vite implementation projects for Multi-Agent System Architectures:

1. **Centralized Architecture (`/Centralized`)**
   - Central hub managing coordinator and worker agents.

2. **Peer-to-Peer Architecture (`/Peer-to-Peer Architecture`)**
   - Decentralized P2P agent negotiation and dynamic mesh communication.

3. **Sequential Pipeline Architecture (`/Sequential  Pipeline Architecture`)**
   - Multi-stage pipeline processing with step-by-step agent workflow execution.

## Getting Started

To run any of the architecture experiments:

```bash
cd "Centralized" # or "Peer-to-Peer Architecture" or "Sequential  Pipeline Architecture"
npm install
npm run dev
```
